the beginning

Linux at nine. Web ever since.

I installed Fedora Core 3 all by myself at the age of nine. That was the gateway, and I've used Linux every single day since. It wasn't a tool I picked up along the way; it's the foundation everything else was built on. Today I run Arch Linux and feel at home deep in the system, from kernel configuration to network hardening.

Not long after that first install, I started learning HTML. Then CSS, then PHP, and the story kept going. By late primary school I was already curious about web security, learning common attack vectors and bug types in web applications. I even built my own webpage in 2005, at the age of twelve: it still exists in the archive.

what drives me

Work that matters, craft for its own sake.

I believe in open source and in doing things driven by love for the craft, not just a paycheck. I have a deep need to use my skills for meaningful impact: to build things that genuinely help people and make a positive difference in the world. Code for code's sake isn't enough; I want the work I do to matter.

I'm very ambitious. These things are my passion and I pursue them regardless of job, payroll, or mood. I want to get involved in something real: code with people I can learn from, and together create something significantly great.

craft
